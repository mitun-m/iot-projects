# IoT Projects

ESP32 projects built and simulated on Wokwi.

## SmartCook - Alert System (milk boil alert)
A DS18B20 sensor reads the milk temperature. At 97 C, which is 3 C before milk boils, the LED blinks and the buzzer beeps.
- Board: ESP32
- Parts: DS18B20, buzzer, LED, resistor
- Simulation: https://wokwi.com/projects/480195136250156033
